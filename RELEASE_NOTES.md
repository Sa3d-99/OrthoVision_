# OrthoVision v1.0.4

v1.0.4 improves noise-aware best-frame scoring and stable selection, adds Best / Latest live preview with manual saving of the displayed original, fixes misleading Disconnected badges for short TCP sender sessions, and displays the installed version in the footer. The main installer is OrthoVision-Setup.exe; a byte-identical version-named release asset preserves automatic update detection for older installed apps. Auto Save still retains at most 10 automatic captures. Startup-only licensing and graceful shutdown are preserved. Technical quality suggestions are not clinically validated; the clinician makes the final selection. Apply updates only after the procedure.

Only the Windows installer is distributed here; app source is private. Image discovery requires a compatible export bridge, not just a LAN cable. No real C-arm integration has been validated.
