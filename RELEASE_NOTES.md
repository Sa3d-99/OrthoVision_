# OrthoVision v1.0.3

Revised v1.0.3: the normal dashboard opens immediately, with no opening activation screen or automatic activation popup. A clipped frosted-glass layer locks the photo section until licensing succeeds. Activate from Settings > License, or use the Open license settings shortcut on the locked image area. Capture reception, discovery/connection, image import, brightness, saving, capture-folder changes, and updates stay disabled until acceptance, with controller-level guards as well as disabled buttons. A valid code entered in Settings immediately unlocks the viewer without a restart. Existing valid saved licenses unlock automatically. RSA-3072 compact and legacy licenses and lifetime licensing remain supported; expiry never interrupts an activated session. 64 automated tests and native Windows startup/shutdown checks passed. This replaces the earlier v1.0.3 installer at the owner request. Users already on v1.0.3 must download the revised installer once because the version number is unchanged. Application source and signing keys are not distributed.

Only the Windows installer is distributed here; app source is private. Image discovery requires a compatible export bridge, not just a LAN cable. No real C-arm integration has been validated.
