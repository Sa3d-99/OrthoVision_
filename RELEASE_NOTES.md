# OrthoVision v1.0.1

Adds Find devices with LAN adapter addresses and cable status, compatible image-export bridge discovery, and one-click connection using an automatically advertised image port. Fixes layout overflow at the minimum window size. Keeps original image retention, brightness, manual saves, graceful shutdown, and approval-based updates. This update requires a supported export bridge; automatic compatibility with a bare C-arm has not been validated.

Only the Windows installer is distributed here; app source is private. Image discovery requires a compatible export bridge, not just a LAN cable. No real C-arm integration has been validated.
