# OrthoVision v1.0.6

v1.0.6: Improved technical Best-frame ranking. Black/white perimeter background and peripheral labels no longer dominate scoring; sampled and native-resolution noise checks reduce false sharpness from grain. Normalized detail/gradients and stronger clipping/blank penalties preserve stable two-point replacement. Corrupt frames cannot replace Best; LAN selection restarts after import. Monotonic header-delivery timing avoids wall-clock/processing-time burst errors. Latest, original saved bytes, startup-only licensing, ten automatic captures and manual saves remain unchanged. 79 automated tests and native Windows receive/full-screen/shutdown checks passed. In-app updates download, close safely, upgrade in place and reopen after operator approval. These are technical heuristics, not a clinically validated image-quality judgment.

Only the Windows installer is distributed here; app source is private. Image discovery requires a compatible export bridge, not just a LAN cable. No real C-arm integration has been validated.
