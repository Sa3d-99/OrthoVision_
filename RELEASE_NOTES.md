# OrthoVision v1.0.5

v1.0.5: Dark glass workspace with decorative overlines removed; integrated title bar and Lucide controls; full-screen viewer (F11 / Escape), fit-to-view, zoom/pan/reset, and display-only Positive/Negative. Updated Setup Guide and reduced-motion-aware finite transitions. Startup-only licensing, worker-isolate reception, original saved pixels, and top-10 automatic retention are preserved. The public root now contains only OrthoVision-Setup.exe; old licensed Releases remain available. In-app updates download, close safely, apply in place, and reopen after operator approval. 73 automated tests, static analysis, and native Windows receive/full-screen/shutdown checks passed.

Only the Windows installer is distributed here; app source is private. Image discovery requires a compatible export bridge, not just a LAN cable. No real C-arm integration has been validated.
